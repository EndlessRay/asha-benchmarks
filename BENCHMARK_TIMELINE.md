# Benchmark timeline: every Asha run, dated and reconciled

Revision of 21 October 2026. One row per run or run-group, in date order. Every row names the build that was measured, the item set with n, the grader, the score, where the artifact lives, and how the number may be used today. Pipeline ids are defined in [`healthbench-2026-06-26/PIPELINES.md`](healthbench-2026-06-26/PIPELINES.md). Where this file and the live register ([dnai.systems/benchmarks](https://dnai.systems/benchmarks)) disagree, the register is right and this file is stale.

**Status key.** `record`: a number DNAi cites publicly, on the register. `lineage`: a past build's number, kept for comparison, cited only with its date. `decision`: an internal configuration-choice study; never a headline, aggregates only. `diagnostic`: a run that answers one question about another run. `comparator`: a bare model or external system scored for comparison. `retired`: superseded or found wrong; kept for the audit trail. `not run`: pre-registered and never executed.

## What the timeline says, read straight

1. **Three Apex-class numbers exist and they are not the same build.** June P6 (Hard 44.8, panel 68.4) is the highest; September Apex-J (Hard 42.0, Standard 60.7, panel 63.8) is the launched build and the only one with a 5,000-item run and a bare comparator; neither is reproducible. The September ladder selected on a length-adjusted Professional score and a harm bound; the official HealthBench metric rewards completeness, so the fuller June answers score higher on it. Both facts are true and both are on the register.
2. **Base, October 2026, is the first measurement on a reproducible freeze.** It shows the single-pass layer adds no HealthBench score over the same model at the same effort, and lifts crisis safety from 87.5 to 100 percent.
3. **The frontier moved.** Bare Claude Sonnet 5.5 at effort max (63.8 on the seed-62 500) scores above the frozen Apex-J (61.6) on the same items under the same grader. The published lift rows hold the composer model fixed and remain true as stated; a claim against the strongest current bare model has not been earned.
4. **The served Apex has no measurement since 14 October.** That is the gap the final run closes.
